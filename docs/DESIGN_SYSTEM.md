# 设计系统：Modern Discovery Workspace

本文件记录 2026-08-31 经确认的 v4 界面约束。正式 Dashboard 采用“每日发现工作台”结构，保留本地优先、证据可解释与反馈可撤回的产品边界。

## 产品构图

- 桌面端：232px 深色侧栏、72px 状态顶栏、四项数据概览、对象列表与粘性详情双栏。
- 平板端：侧栏收为 84px 图标轨，列表与详情仍并排。
- 手机端：单列阅读，详情优先，底部提供四项主导航；页面级禁止横向滚动。
- 一级页面：今日发现、历史日报、我的收藏、反馈记录。
- 今日阅读顺序：日报概览 → 类型筛选 → 推荐列表 → 项目详情 → 证据趋势 → 推荐原因 → 反馈。

## 视觉令牌

| 角色 | 值 | 用途 |
|---|---|---|
| 页面背景 | `#f4f6fa` | 工作区背景 |
| 主表面 | `#ffffff` | 列表、详情与指标卡 |
| 侧栏 | `#0e1628` | 一级导航与本地模式状态 |
| 主文字 | `#162033` | 标题与关键数据 |
| 次文字 | `#4f5c73` | 简介与辅助说明 |
| 品牌靛蓝 | `#5b5ce2` | 选中态、主按钮与趋势线 |
| 健康绿 | `#159b72` | 正增长、健康与成功状态 |
| 警告黄 | `#c47a13` | 等待、降级与待同步 |
| 危险红 | `#c94b5d` | 错误与撤回动作 |

圆角分为 10px 控件、16px 普通卡片、22px 主工作区；阴影只用于建立层级，不用于装饰性堆叠。

## 字体与密度

- 中文正文使用 `Microsoft YaHei UI`、`Segoe UI Variable Text` 与系统 sans-serif；不依赖网络字体。
- 标题为 21–38px，列表主标题为 12–15px，正文为 10–14px。
- 日期、排名、Star 与证据标签使用系统 monospace。
- 移动端所有主要按钮和链接点击区域至少 44px；装饰性小标签不作为操作入口。

## 核心组件

- `AppSidebar`：品牌、四项一级导航、日报与中文增强状态。
- `TopbarStatus`：日报日期、数据刷新、MiniMax 与反馈同步弹层。
- `MetricOverview`：每页四个与当前业务对象直接相关的指标。
- `RecommendationToolbar`：按兴趣、快速涨星、探索筛选；客户端筛选保持详情联动。
- `ObjectList`：推荐、日报或收藏列表；选中对象使用靛蓝底色和左侧信号线。
- `ProjectDetail`：仓库身份、中文摘要、原始简介、GitHub 动作、指标、趋势、理由与反馈。
- `FeedbackBar`：同一项目单选；只有当前选项使用实色主色与“已选”标记，再次点击取消，选择其他项替换旧反馈。
- `FeedbackLedger`：桌面表格、手机卡片；撤回保留原记录并需要确认。
- `StateNotice`：空、样例、模型降级、数据失败与同步失败必须靠近受影响内容。

## 行为与安全

- FastAPI + Jinja + HTMX 仍是唯一前端栈，不引入客户端框架。
- 对象切换、反馈保存、反馈撤回、数据检查与反馈同步不得退化为整页重载。
- 外部 GitHub 链接必须新窗口打开并使用 `noopener noreferrer`。
- 反馈写入、撤回与同步继续保留 CSRF、同源校验与人工确认。
- 支持键盘焦点、`aria-current`、`aria-pressed`、`aria-live` 与 `prefers-reduced-motion`。

任何新增一级页面、公开私人事实、自动推送反馈或隐藏降级状态都属于需求变更。

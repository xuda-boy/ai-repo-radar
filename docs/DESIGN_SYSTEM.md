# 设计系统：Signal Ledger

本文件把已批准的高保真 v2 原型转换为正式实现约束。实现不得自行改回重复卡片流。

## 产品构图

- 主要模式：紧凑对象索引控制单个详情画布。
- 一级页面：今日、历史、收藏；不增加营销首页、登录页或 KPI 拼图。
- 阅读顺序：项目信号 → 仓库身份 → Star 证据 → 推荐原因 → 快速开始 → 反馈。
- 容器：深色导航轨、浅色索引、白色阅读画布；以分隔线组织，而不是层层圆角卡片。

## 字体

- 编辑型标题：`Noto Serif SC`，500。
- UI 正文：`Noto Sans SC`，400/500。
- 仓库名、日期、指标：`IBM Plex Mono`，400/500。
- 网络字体不可用时，分别回退到系统 serif、Microsoft YaHei 和 monospace。

## 组件族

- `AppRail`：三个一级页面，桌面纵向、窄屏横向，选中状态有橙色信号线。
- `ContextBar`：页面标题、说明、日期和数据／模型／反馈状态。
- `ObjectIndex`：仓库、日期或收藏的高密度列表；一次只能选中一个对象。
- `DetailCanvas`：开放式内容区域，不嵌套卡片。
- `MetricBand`：五项指标使用连续分隔带。
- `StarTrace`：服务端生成的响应式 SVG；只显示必要刻度和终点值。
- `FeedbackBar`：四个明确动作，主动作是“更多此类”；移动端按钮高度至少 44px。
- `StateNotice`：加载、空、模型降级、数据失败和同步失败必须靠近受影响内容。

## 动效与无障碍

- 对象切换使用 180ms 以内的轻微淡入和位移。
- 支持 `prefers-reduced-motion`。
- 一级导航使用 `aria-current`，状态提示使用 `aria-live`。
- 所有交互支持键盘焦点；焦点样式不得依赖颜色变化 alone。

## 允许的可见文案

- 一级导航：今日、历史、收藏。
- 页面标题：今日推荐、历史日报、已收藏。
- 推荐动作：更多此类、收藏、不相关、已了解。
- 证据标识：实测、估算。
- 同步状态：已本地保存、同步中、已同步、同步失败待重试。
- 降级状态：AI 中文摘要暂不可用。

任何新增一级页面、营销文案、指标卡或可见隐私字段都属于需求变更。

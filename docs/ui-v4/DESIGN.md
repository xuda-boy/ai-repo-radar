# UI v4 Design

## Goal

把 AI Repo Radar 从“能阅读的日报”升级为“可以每天快速决策的项目发现工作台”，同时保持本地优先和可解释性。

## Information architecture

1. 先确认日报日期、任务状态与中文增强完成度。
2. 用四项概览理解当天信号规模和结构。
3. 按推荐类型筛选，在列表中比较摘要、语言、增长和证据。
4. 在详情中判断项目是什么、为什么推荐、如何开始。
5. 打开 GitHub 或提交次日生效的反馈。

历史页复用“日期清单 → 当日报告”，收藏页复用“研究清单 → 项目上下文”，反馈页使用“状态概览 → 审计明细”。

## Responsive behavior

- `>1180px`：完整侧栏与双栏工作区。
- `901–1180px`：84px 图标侧栏，双栏收窄。
- `<=900px`：手机顶栏、单列详情优先、底部主导航。
- `<=620px`：2×2 概览、四等分筛选、两列反馈动作、反馈表格转卡片。

## State coverage

- 正常增强日报、固定样例、模型降级。
- 无日报、无收藏、无反馈、趋势快照不足。
- 待同步、仅本地、同步成功、同步失败。
- 自动刷新等待、检查中、无变化与新日报重载。

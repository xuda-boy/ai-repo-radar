# UI Audit

## Before

- 旧版视觉以米色纸张、橙色信号线和等宽数据排版为主，字体观感偏工具化。
- 页面主体更像日报阅读器，缺少清晰的“发现 → 比较 → 打开 → 反馈”工作路径。
- 今日页没有汇总当天候选、增长与中文增强完成度。
- 历史、收藏与反馈使用不同的视觉结构，学习成本较高。
- 手机端虽可用，但主对象、详情和操作优先级不够明确。

## Improvements made

- 统一为深海军蓝侧栏、浅灰工作区、白色业务表面和靛蓝主动作。
- 四个页面都使用“页首说明 → 四项概览 → 主工作区”的稳定层级。
- 今日新增推荐类型筛选并保持 HTMX 详情联动。
- 项目详情将中文简介置于第一阅读层，英文原始简介按需展开。
- 历史、收藏与反馈沿用同一对象清单、详情和指标语言。
- 手机端改为详情优先单列与固定底部导航，主要点击区域至少 44px。

## Preserved behavior

- GitHub 外链、CSRF、同源校验、反馈次日生效、撤回审计、数据刷新与私人仓同步均保持原语义。
- 样例、估算、模型降级与待同步状态仍明确可见。
- Dashboard 继续只服务于 `127.0.0.1`。
